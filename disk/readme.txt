xyuOS Neo -- your files live here
=================================

This folder is yours. Anything you save from Notepad, or copy off a USB
stick, can go here and it will still be here after a reboot -- provided you
put it on the stick, because the root filesystem lives in RAM on real
hardware and forgets everything when the power goes.

Getting started
---------------

  Ctrl+Esc            open the start menu, then type to search
  Click the orb       same thing, with the mouse
  Super+Enter         a new terminal window
  Alt+Tab             switch windows
  Alt+F4              close the focused window
  Super+Left/Right    snap a window to half the screen
  Drag to an edge     the same, with the mouse

The programs
------------

  Files       browse folders, rename, delete, open things
  Notepad     a text editor with a caret you can point at
  Viewer      PNG, JPEG, BMP and plain text
  Task manager  what is running, and how to make it stop

Try opening /pics with Files and double-clicking a picture.
